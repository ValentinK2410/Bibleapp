## Почему стоит попробовать

- **Не нужен интернет для чтения** — Синодальный, НРП, РБО, Кулаковых, WEB, подстрочник Винокурова уже внутри.
- **Озвучка — как в аудиокниге** — несколько дикторов, скорость, таймер сна, скачивание в фоне, таймкоды к стихам.
- **Для тех, кто хочет глубже** — комментарии, Стронг, родословная, карты, план «Библия за год», изучение языков.
- **Для жизни, не только для чтения** — заметки, медиа, песнопение, путешествия на карте, детский раздел, DeepSeek и GigaChat.

> Это приложение делалось не «для галочки в сторе», а для реального ежедневного чтения — с теми мелочами, которые каждый день радуют: стих дня, тепловая карта истории, свои цвета вкладок переводов, оформление «папирус» или «кожаный свиток».
