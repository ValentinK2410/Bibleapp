Разметка слов по клику

Клик по слову без метки — записать текущее время дорожки. Клик по слову с меткой — воспроизвести файл с этой отметки. Ctrl+клик — перезаписать метку. Shift+клик — сбросить. Экспорт — JSON для «Ночное чтение».

Вставьте текст и нажмите «Разбить на слова». Клик по слову записывает текущее время дорожки в миллисекундах.

Сначала разбейте текст на слова.

Файл содержит marks (сырые клики) и words для плеера: start/end в секундах.
